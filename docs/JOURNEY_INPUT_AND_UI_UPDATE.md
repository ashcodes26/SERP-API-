# Journey input and simpler screens

My journey now has an **Add journey details (CSV / Excel)** input page, also available as **Update journey details** after loading a profile. Choose a file, inspect the preview, confirm it describes your own background, and save to continue to the career profile and existing skill-gap journey. Web users can download a CSV template; the same columns work in Excel.

Supported columns: `name`, `program`, `department`, `specialization`, `semester`, `cgpa`, `graduation_year`, `skills`, `summary`. Common column aliases such as Full Name and Degree are recognized. Separate skills with semicolons, commas or pipes. Use exactly one student row and the first Excel worksheet; accepted formats are UTF-8 CSV and XLSX, up to 1 MiB. Blank cells retain current profile values. Unsupported columns, including student ID and email, appear as ignored in the preview. Excel expansion is bounded at 20 MiB.

`POST /api/journey/input/preview` parses without storing the file or modifying the profile. `POST /api/journey/input/save` accepts reviewed details only for the authenticated student. A profile digest rejects a save when the profile has changed since preview. New skill mentions have unknown (`null`) proficiency and self-reported evidence; existing assessed levels and evidence are preserved. Repeated identical input does not duplicate evidence. The existing administrator batch import remains available separately. The prototype still uses its existing demo authentication and student record; production onboarding is outside this change.

Skill demand now shows role, location, **Show skill demand** and **More options**, followed by the three existing views. The duplicated Actions menu and role/location shortcut button lists were removed from this screen. Dates, fresh collection, reset, CSV export and technical ranking details appear under More options. Stored-data filtering and live SerpApi collection retain their existing behavior and source labels.

LinkedIn's **Retrieve and review your profile** input card appears before career-direction controls and insights. The **SAVED PROFILE ANALYSIS** card and repeated parsed-section listing were removed completely. Career coaching, public lookup, connection and reviewed save remain available.

Files changed for this update: backend schemas, private-workspace routes and middleware; new `app/services/journey_input.py` and `tests/test_journey_input.py`; mobile contracts and API client; `app/index.tsx`, `app/market.tsx`, `app/linkedin.tsx`, new `components/journey-input.tsx`; browser verification script, README and this report. The roadmap test fixture now uses UTC dates to match the endpoint's existing today filter instead of depending on the host's date around midnight.

No dependencies, environment variables or database migration are required. Physical Android/iOS file-picker acceptance remains outstanding.
